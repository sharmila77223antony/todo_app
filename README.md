# ✨ Todo App

A modern, responsive Todo App built with **React.js** to manage daily tasks with a clean and user-friendly interface.

🚀 **Live Demo:** https://todo-app-ten-gamma-64.vercel.app/

## ✨ Features
- ➕ Add and manage tasks
- ✅ Track task completion
- 🎨 Clean and responsive UI
- ⚡ Smooth and interactive experience

## 🛠️ Tech Stack
- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## 💻 Run Locally

```bash
git clone https://github.com/sharmila77223antony/todo_app.git
cd todo_app
npm install
npm run dev
```
